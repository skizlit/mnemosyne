# Mnemosyne v0.1 proof

## Question

Can Mnemosyne remember useful knowledge across separate runs and correctly replace outdated
knowledge?

## Synthetic scenario

1. A new vault stores: “Casey's preferred editor theme is light.”
2. The process ends.
3. A new process asks for Casey's editor preference and receives “light.”
4. A correction states: “Casey's preferred editor theme is dark.”
5. The process ends again.
6. A third process asks the same question and receives “dark.”
7. “Light” remains available only as history or provenance, not as a second current answer.
8. The current memory can be opened, understood, and edited in Obsidian as Markdown.

## Pass conditions

- The result survives a complete process restart.
- Retrieval finds the relevant memory without an exact filename.
- A correction updates the same logical memory.
- Retrieval returns one unambiguous current answer.
- The Markdown remains valid and readable without Mnemosyne.
- No database or model is required for the proof.
- Automated tests use only synthetic data.
